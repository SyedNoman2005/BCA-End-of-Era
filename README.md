# 🚀 BCA APEX 2026 – AI Photo Frame Generator

A premium, interactive web application that allows users to upload photos, apply professional frames, adjust positioning, and export high-quality images — powered by modern frontend technologies and AI-based face utilities.

---

## 🎯 What This Project Does

This is not a simple webpage.

It is a **client-side image processing tool** that enables:

* Uploading user photos
* Applying dynamic graduation frames
* Drag, zoom, and reposition image
* Compare before/after
* Export final high-resolution image
* (Optional) AI-based face handling using face-api.js

---

## 🔥 Key Features

* 🧠 Smart image positioning (drag, scale, transform)
* 🎨 Premium glassmorphism UI
* ⚡ Smooth animations & micro-interactions
* 🖼️ Multiple frame selection system
* 🔍 Before/After comparison slider

## ▶️ How to Run This Project

### Method 1: Direct Run (Basic)

1. Download or clone the repository
2. Keep all frame images (`1.png`, `2.png`, etc.) in same folder
3. Open `index.html` in browser

---

### Method 2: Live Server (Recommended)

1. Install **VS Code**
2. Install **Live Server extension**
3. Right-click `index.html`
4. Click **Open with Live Server**

👉 Why this matters:

* Prevents file path issues
* Ensures smooth JS execution
* Better performance

## 🧠 How It Works (Simple Explanation)

1. User uploads image
2. Image is rendered on canvas layer
3. Transform controls allow scaling & movement
4. Frame overlays on top
5. Canvas exports final composed image
